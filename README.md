# Python Diary

Learning Python from zero. No courses, no tutorials.
Just real problems, real code, documented as I go.

## Method

One concept per session. I write the code myself — no copy paste.
Each file starts with what I learned before the code runs.
AI as tutor, not as crutch.

## How to use this as a learning template

If you want to learn the same way:

- Pick a real project you care about. No fake exercises.
- One concept per session, fully understood before moving on.
- Type everything yourself. Muscle memory matters.
- Use AI as a tutor — let it ask you questions, not give you answers.
- When stuck, guess first. Then ask.

## Tutor instructions (for AI)

- Ask me to explain code before correcting it.
- Let me find bugs myself — hints only, not answers.
- One new concept at a time. No more.
- Short explanations. I ask if I need more.
- If I already understand something, tell me explicitly.

## Structure

Files named `NN-concept.py`. Two digits, dash, concept.
Comments explain the why, not just the what.
